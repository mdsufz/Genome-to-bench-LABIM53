# Metadata and evidence

This directory records structured evidence recovered from the manuscript,
dissertation and supplied figures. It is intentionally separate from large
sequence and result files.

- `pgpr_gene_targets.tsv` records the potassium- and phosphorus-solubilisation
  targets, UniProt accessions and supporting references listed in Appendix A,
  Table A1 of the dissertation.
- `accessions/uniprot_targets.tsv` provides the 20 unique UniProt targets.
- `accessions/circular_comparison_genomes.tsv` provides the accessions of the
  12 comparison rings in Figure 1.
- `accessions/pangenome_genomes.tsv` provides LABIM53 and the 14 public genomes
  used for comparative analysis.
- `accessions/ani_phylogeny_genomes.tsv` records accession-supported taxa shared
  by the dissertation table and the manuscript taxonomy figures.
- `accessions/marker_sequences.tsv` retains the schema for marker accessions.
- `reported_results.yaml` records manuscript values, figure/table values and
  any discrepancy between them.
- `repository_settings.yaml` records the public repository description/topics.

The repository is a manuscript companion and reusable workflow template. Exact
historical output files are not required for using the instructions. Where an
original output is unavailable, the repository provides the reported value,
the supplied final asset, a transparent limitation and rerun instructions.

The accession tables contain only identifiers supported by the cited sources.
