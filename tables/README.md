# Manuscript tables and provenance

This directory contains manuscript tables that could be recovered from the
supplied article.

## Table 1 - PlasFlow classifications
Table 1. Predicted PlasFlow classification of LABIM53 contigs. 
a Contig name: GenBank accession identifier assigned to each contig.
b Contig length (bp): total length of the contig expressed in base pairs.
c Label: PlasFlow-predicted genomic origin (chromosome or plasmid) and the associated taxonomic assignment (Firmicutes, Proteobacteria, Spirochaetes, or unclassified).

## Table 2AB - Gene-mining results
Table 2A. Genome mining of genes associated with organic acid production linked to nutrient solubilisation.
a Acid indicates the organic acid or metabolite identified through genome mining.
b Coverage indicates the percentage of the reference sequence covered by the alignment.
c Identity indicates the percentage of sequence similarity between the LABIM53 sequence and the reference sequence.
d Expected action indicates the predicted role of the identified metabolite in potassium and/or phosphate solubilisation.

Table 2B. Genes associated with organic acid production and linked to nutrient solubilisation.
a UniProt accession indicates the unique identifier to the protein sequence in the UniProt database.
b Gene name indicates the standardized name  of the gene associated with organic acid production.
c Source organism indicates the strain from which the reference sequence was obtained
d Trait category indicates whether the gene is associated with potassium or phosphorus solubilisation.
